# Ontology Branding

Ontology uses a dark open-source-safe identity across shared app chrome and retail ontology surfaces.

## Palette

| Role | Hex |
| --- | --- |
| Background | `#222222` |
| Text | `#FFFFFF` |
| Primary blue | `#17456A` |
| Accent blue | `#86C6CA` |
| Alert red | `#F12924` |
| Neutral dark | `#010101` |

## Usage Notes

- Use the committed `public/ontology-mark.svg` and `public/favicon.svg` for repo-safe builds.
- Keep private source logo files under `docs/branding/local-assets/`; that folder is gitignored.
- Use semantic table colors for source, derived, inferred, and alert states. Do not encode legacy identity colors or names in component, route, storage, or API symbols.
